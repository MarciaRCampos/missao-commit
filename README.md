# Missão Commit: Git e GitHub do zero

Curso gamificado de Git e GitHub, em 6 capítulos, com a história da Rita (analista sênior) ensinando o Téo (estagiário) na Kora Labs, em Brasília.

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Conteúdo

- Prova rápida no início de cada capítulo: quem acerta tudo pode pular o capítulo.
- Correção imediata com a explicação do porquê.
- Entrevista final com 3 respostas possíveis e feedback.
- Projeto de portfólio no GitHub (repositório, README e instruções).
- Narração em áudio (pasta `audio/`), com voz do navegador como alternativa quando o arquivo não existir.

## Progresso

O progresso é salvo no navegador (chave `mg_missao_commit_v1`).

O método segue o Círculo Dourado (por quê, como, o quê), sem citar o nome da técnica ao aluno.
